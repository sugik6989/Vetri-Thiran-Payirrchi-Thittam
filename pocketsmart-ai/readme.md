# PocketSmart AI - Smart Budget & Recommendation Assistant

An AI-powered budget planning and recommendation system for home interiors, party planning, and jewelry selection.

## Features

- 🏠 **Home Interior Budget Planner** - Get furniture, lighting, and decor recommendations
- 🎉 **Party Budget Planner** - Plan events with venue, catering, and decoration suggestions
- 💎 **Jewelry Budget Planner** - Find jewelry matching your outfit and occasion
- 🤖 **AI-Powered** - Uses Google Gemini 1.5 Flash Pro for intelligent recommendations
- 🛍️ **Multi-Platform Links** - Direct shopping links to Amazon, Flipkart, IKEA, Swiggy, Zomato, and more
- 📊 **History Tracking** - Save and review past recommendations
- 🔐 **User Authentication** - Secure JWT-based login system

## Tech Stack

- **Backend**: FastAPI (Python)
- **AI**: Google Gemini 1.5 Flash Pro
- **Frontend**: HTML, CSS, JavaScript, Jinja2
- **Authentication**: JWT tokens with bcrypt password hashing
